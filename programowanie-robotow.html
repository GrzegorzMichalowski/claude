Jazda prosto — PID na żyroskopie

Korekcja proporcjonalna + całkująca + różniczkująca

▼ 
def drive_straight(distance_cm, speed=400, Kp=1.5, Ki=0.0, Kd=0.8):
    """Jedzie prosto z korekcją PID na żyroskopie."""
    import math
    motion_sensor.reset_yaw_angle()
    motor.reset_relative_position(LEFT_MOTOR, 0)

    circ = math.pi * WHEEL_DIAMETER_MM / 10  # cm
    target_deg = (distance_cm / circ) * 360

    integral, last_error = 0.0, 0.0

    while abs(motor.relative_position(LEFT_MOTOR)) < target_deg:
        error = motion_sensor.tilt_angles()[0] / 10  # decidegrees → degrees
        if abs(error) < 0.5:
            integral = 0.0
        else:
            integral = max(-30, min(30, integral + error))
        derivative = error - last_error
        correction  = int(Kp*error + Ki*integral + Kd*derivative)
        correction  = max(-200, min(200, correction))
        motor.run(LEFT_MOTOR,  speed - correction)
        motor.run(RIGHT_MOTOR, speed + correction)
        last_error = error

    motor_pair.stop(motor_pair.PAIR_1, stop=motor.BRAKE)
O co chodzi? Robot jedzie prosto, ale bez żyroskopu zawsze trochę skręca — jedno koło kręci się odrobinę szybciej. Ten kod sprawdza co chwilę czy robot jest skrzywiony i na bieżąco koryguje oba silniki. To tak jak ty trzymasz kierownicę samochodu — ciągle robisz drobne korekty żeby nie zjechać z drogi.
motion_sensor.reset_yaw_angle()
Zerujemy "kompas" robota. Mówimy mu: "teraz stoisz prosto — to jest Twój punkt startowy, kąt = 0°". Bez tego robot nie wiedziałby, od czego mierzyć skrzywienie.
motor.reset_relative_position(LEFT_MOTOR, 0)
Resetujemy licznik obrotu lewego silnika do zera. Dzięki temu będziemy wiedzieć ile silnik się już obrócił, czyli jak daleko robot pojechał.
Jak wyzerowanie licznika kilometrów przed podróżą.
target_deg = (distance_cm / circ) * 360
Przeliczamy centymetry na stopnie obrotu silnika. Koło o średnicy 56mm ma obwód ~17,6 cm. Żeby pojechać 50 cm, silnik musi się obrócić: (50 / 17,6) × 360 = ok. 1022°.
Jak liczenie ile razy rower musi zakręcić kołem żeby dojechać do sklepu.
while abs(motor.relative_position(LEFT_MOTOR)) < target_deg:
Pętla: "Rób wszystko poniżej, dopóki silnik nie obrócił się tyle ile zaplanowaliśmy." abs() bierze wartość bezwzględną — działa zarówno dla jazdy w przód jak i w tył.
error = motion_sensor.tilt_angles()[0] / 10
Pytamy żyroskop: "o ile stopni jesteś teraz skrzywiony?". Żyroskop mierzy w dziesiątych stopnia (decidegrees), więc dzielimy przez 10 żeby mieć normalne stopnie. Jeśli robot skręcił w prawo o 2°, error = 2.
integral = max(-30, min(30, integral + error))
Sumujemy wszystkie błędy z przeszłości (Ki — człon całkujący). Jeśli robot przez 5 sekund troszkę skręcał w prawo, integral się nazbierał i wymusi mocniejszą korektę. Ograniczamy do ±30 żeby korekcja nie "wariowała".
Jak pamiętanie że w tej sali zawsze wieje od okna — bierzesz to pod uwagę z wyprzedzeniem.
derivative = error - last_error
Sprawdzamy czy błąd rośnie czy maleje. Jeśli robot szybko skręca w prawo (błąd rośnie), reagujemy mocniej zanim skrzywienie stanie się duże.
Kd = patrz nie tylko gdzie jesteś, ale też w którą stronę zmierzasz.
correction = int(Kp*error + Ki*integral + Kd*derivative)
Liczymy całkowitą korektę z trzech składników. To jest serce algorytmu PID. Wynik mówi: "o ile deg/s jeden silnik powinien być szybszy od drugiego".
motor.run(LEFT_MOTOR, speed - correction)
motor.run(RIGHT_MOTOR, speed + correction)
Jeśli robot skręcił w prawo (error > 0, correction > 0): lewy silnik zwalnia, prawy przyspiesza → robot prostuje się w lewo. Jeśli skręcił w lewo: odwrotnie. Suma prędkości zawsze = 2×speed.
Jak ciągnięcie za lejce konia: pociągnij lewy → skręt w lewo.
ParametrDomyślnieZakresOpis
distance_cm—>0 przód, <0 tyłDystans w centymetrach
speed400200–700 deg/sPrędkość bazowa
Kp1.50.5–3.0Wzmocnienie proporcjonalne
Ki0.00–0.3Całkujące (zacznij od 0)
Kd0.80–2.0Różniczkujące (tłumi oscylacje)
Strojenie: Zacznij od Kp=1.5, Ki=0, Kd=0. Zwiększaj Kp aż robot dryfuje, potem dodaj Kd ≈ Kp/2 żeby wytłumić wibracje. Ki dodaj tylko gdy robot stale skręca w jedną stronę.

Skręt o dokładny kąt

PD controller — precyzja ±1°

def turn_gyro(angle, speed=200, Kp=2.0, Kd=0.5):
    """Skręt w miejscu o zadany kąt. + prawo, - lewo."""
    motion_sensor.reset_yaw_angle()
    last_error = 0.0

    while True:
        current = motion_sensor.tilt_angles()[0] / 10
        error   = angle - current
        if abs(error) <= 1.0:
            break
        correction = int(Kp * error + Kd * (error - last_error))
        correction = max(-speed, min(speed, correction))
        # Minimalna prędkość żeby robot się poruszył
        if 0 < abs(correction) < 80:
            correction = 80 if correction > 0 else -80
        motor.run(LEFT_MOTOR,   correction)
        motor.run(RIGHT_MOTOR, -correction)
        last_error = error

    motor_pair.stop(motor_pair.PAIR_1, stop=motor.BRAKE)


# Wariant: skręt na jednym kole (szerszy łuk)
def turn_one_wheel(angle, pivot='right', speed=200):
    """Skręt łukowy: pivot='right' lub 'left'."""
    motion_sensor.reset_yaw_angle()
    while True:
        error = angle - motion_sensor.tilt_angles()[0] / 10
        if abs(error) <= 1.5: break
        spd = max(-speed, min(speed, int(1.5 * error)))
        if 0 < abs(spd) < 60: spd = 60 if spd > 0 else -60
        if pivot == 'right':
            motor.run(LEFT_MOTOR, spd); motor.stop(RIGHT_MOTOR)
        else:
            motor.stop(LEFT_MOTOR); motor.run(RIGHT_MOTOR, -spd)
    motor_pair.stop(motor_pair.PAIR_1, stop=motor.BRAKE)
O co chodzi? Robot obraca się w miejscu — jedno koło jedzie do przodu, drugie do tyłu. Żyroskop mierzy co chwilę o ile stopni się już obrócił i kiedy dojdzie do celu, zatrzymuje się. Im bliżej celu, tym wolniej (żeby nie "przeskoczył").
motion_sensor.reset_yaw_angle()
Zerujemy kompas przed skrętem. Od tej chwili robot mierzy kąt od zera. Jeśli chcemy skręcić o 90°, robot będzie kręcił się aż żyroskop pokaże 90°.
current = motion_sensor.tilt_angles()[0] / 10
Odczytujemy aktualny kąt obrotu w stopniach. Na początku = 0°. Po obróceniu w prawo o 45° = 45°.
error = angle - current
Obliczamy ile stopni zostało do celu. Jeśli cel to 90° a robot jest na 60°, error = 30°. Gdy robot dojdzie do celu, error = 0.
Jak nawigacja GPS: "zostało Ci 30 km do celu".
if abs(error) <= 1.0: break
Jeśli błąd jest mniejszy niż 1 stopień — zatrzymaj się, jesteśmy w miejscu docelowym. Tolerancja 1° jest wystarczająco precyzyjna do zawodów.
correction = int(Kp * error + Kd * (error - last_error))
Liczymy prędkość obrotu. Daleko od celu (duży error) → kręcimy szybko. Blisko celu (mały error) → kręcimy wolno. To zapobiega "przeskoczeniu" o za dużo.
Jak parkowanie auta: z daleka jedziesz normalnie, przy samym miejscu prawie się czołgasz.
if 0 < abs(correction) < 80: correction = 80
Minimalna prędkość żeby silniki w ogóle ruszyły. Silniki LEGO mają martwy punkt — przy zbyt małym sygnale stoją w miejscu. Wymuszamy minimum 80 deg/s.
motor.run(LEFT_MOTOR, correction)
motor.run(RIGHT_MOTOR, -correction)
Lewy silnik jedzie do przodu (+), prawy do tyłu (−). To powoduje obrót w miejscu (skręt w prawo). Gdyby oba silniki jechały w przód, robot pojechałby do przodu, a nie obrócił się.
Jak czołg: żeby skręcić w prawo, lewa gąsienica jedzie do przodu a prawa do tyłu.
PrzykładEfekt
turn_gyro(90)Skręt 90° w prawo (w miejscu)
turn_gyro(-45)Skręt 45° w lewo
turn_gyro(180, 150)Obrót 180°, wolniej (precyzyjniej)
turn_one_wheel(90)Łuk 90° na prawym kole
Wskazówka: Przy kątach >90° użyj mniejszego speed (150–200). Żyroskop może dryfować po długim biegu — zawsze wywołaj reset_gyro() przed każdym skrętem.

Kontroler proporcjonalny — krawędź czarnej linii

from color_sensor import reflection

def follow_line(distance_cm, speed=300, sensor_port=None,
                side='right', Kp=1.2):
    """
    Jedzie wzdłuż krawędzi linii (proportional control).
    side='right' = prawa krawędź, 'left' = lewa krawędź
    """
    import math
    if sensor_port is None: sensor_port = COLOR_FRONT
    motor.reset_relative_position(LEFT_MOTOR, 0)
    circ = math.pi * WHEEL_DIAMETER_MM / 10
    target_deg = (distance_cm / circ) * 360
    TARGET = 50  # krawędź linii (0=czarny, 100=biały)

    while abs(motor.relative_position(LEFT_MOTOR)) < target_deg:
        ref    = reflection(sensor_port)
        error  = ref - TARGET
        if side == 'left': error = -error
        correction = max(-300, min(300, int(Kp * error)))
        motor.run(LEFT_MOTOR,  speed - correction)
        motor.run(RIGHT_MOTOR, speed + correction)

    motor_pair.stop(motor_pair.PAIR_1, stop=motor.BRAKE)


def follow_line_until_color(target_color, speed=250,
                             sensor_port=None, side='right', Kp=1.2):
    """Jedzie po linii aż wykryje zadany kolor."""
    from color_sensor import reflection, color as cscolor
    if sensor_port is None: sensor_port = COLOR_FRONT
    TARGET = 50

    while cscolor(sensor_port) != target_color:
        ref   = reflection(sensor_port)
        error = (ref - TARGET) if side == 'right' else -(ref - TARGET)
        correction = max(-300, min(300, int(Kp * error)))
        motor.run(LEFT_MOTOR,  speed - correction)
        motor.run(RIGHT_MOTOR, speed + correction)

    motor_pair.stop(motor_pair.PAIR_1, stop=motor.BRAKE)
O co chodzi? Robot nie jedzie po linii — jedzie wzdłuż krawędzi linii. Czujnik koloru mierzy ile światła odbija się od podłogi (0 = czarny, 100 = biały). Krawędź linii to punkt środkowy ~50. Robot stara się ciągle trzymać czujnik dokładnie na tej granicy czarno-białej.
TARGET = 50
Cel to wartość 50 — punkt w połowie między czarnym (~15) a białym (~85). To jest krawędź linii. Robot będzie starał się utrzymać czujnik dokładnie w tym miejscu.
Jak jazda rowerem: trzymasz się linii krawężnika, nie wjeżdżasz na chodnik ani na jezdnię.
ref = reflection(sensor_port)
Odczytujemy ile światła odbija się od podłogi w tej chwili. Jeśli czujnik jest nad czarną linią — ref będzie małe (ok. 15). Nad białą matą — duże (ok. 85).
error = ref - TARGET
Obliczamy jak bardzo czujnik odchylił się od krawędzi. Nad czarnym: error = 15 − 50 = −35 (za bardzo w lewo). Nad białym: error = 85 − 50 = +35 (za bardzo w prawo).
if side == 'left': error = -error
Jeśli śledzimy lewą krawędź linii zamiast prawej, odwracamy znak błędu. Inaczej robot skręcałby w złą stronę.
correction = max(-300, min(300, int(Kp * error)))
Przeliczamy błąd na korektę prędkości. Im dalej od krawędzi, tym mocniej skręcamy. Ograniczamy do ±300 żeby robot nie kręcił się w kółko przy dużym błędzie.
motor.run(LEFT_MOTOR, speed - correction)
motor.run(RIGHT_MOTOR, speed + correction)
Gdy czujnik jest za bardzo na białym (error > 0, correction > 0): lewy silnik zwalnia, prawy przyspiesza → robot skręca w lewo z powrotem na krawędź. Działa ciągle w pętli — robot węży się wzdłuż linii.
Jak slalom: trochę w lewo, trochę w prawo, cały czas w okolicach linii.
ParametrWartośćWskazówka
TARGET (krawędź)50Środek między czarnym a białym — zmień jeśli linia jest wąska
Kp startowe1.2Zwiększaj po 0.2 aż robot jest płynny
Pozycja czujnika3–4 studs przed osiąNajbardziej stabilna pozycja montażu

Wyrównanie do linii

Dwa czujniki — precyzyjne ustawienie prostopadle

▼ 
from color_sensor import reflection
import time

def line_square(speed=150, timeout_ms=3000):
    """
    Wyrównuje robota do czarnej linii — wymaga 2 czujników!
    COLOR_LEFT i COLOR_RIGHT muszą być symetrycznie.
    Każdy silnik zatrzymuje się gdy jego czujnik wykryje czerń.
    """
    left_done = right_done = False
    start = time.ticks_ms()

    motor.run(LEFT_MOTOR,  speed)
    motor.run(RIGHT_MOTOR, speed)

    while not (left_done and right_done):
        if time.ticks_diff(time.ticks_ms(), start) > timeout_ms:
            print("TIMEOUT: line_square!")
            break
        if not left_done and reflection(COLOR_LEFT) < 30:
            motor.stop(LEFT_MOTOR);  left_done  = True
        if not right_done and reflection(COLOR_RIGHT) < 30:
            motor.stop(RIGHT_MOTOR); right_done = True

    motor_pair.stop(motor_pair.PAIR_1, stop=motor.BRAKE)


def line_square_backward(speed=150, timeout_ms=3000):
    """To samo co line_square() ale jadąc do tyłu."""
    left_done = right_done = False
    start = time.ticks_ms()
    motor.run(LEFT_MOTOR,  -speed)
    motor.run(RIGHT_MOTOR, -speed)
    while not (left_done and right_done):
        if time.ticks_diff(time.ticks_ms(), start) > timeout_ms: break
        if not left_done and reflection(COLOR_LEFT) < 30:
            motor.stop(LEFT_MOTOR);  left_done  = True
        if not right_done and reflection(COLOR_RIGHT) < 30:
            motor.stop(RIGHT_MOTOR); right_done = True
    motor_pair.stop(motor_pair.PAIR_1, stop=motor.BRAKE)
O co chodzi? Robot jedzie powoli do czarnej linii. Ma dwa czujniki — lewy i prawy. Każdy silnik zatrzymuje się niezależnie gdy jego czujnik wykryje czerń. Jeśli np. lewa strona dojdzie do linii wcześniej — lewy silnik staje, a prawy jedzie dalej aż "dogoni". W efekcie robot ustawia się prostopadle do linii.
left_done = right_done = False
Tworzymy dwie "flagi" — znaczniki czy dany silnik już się zatrzymał. Na początku oba są False (nie zatrzymane).
start = time.ticks_ms()
Zapamiętujemy czas startu. Jeśli po 3 sekundach robot nadal nie znalazł linii — przerywamy żeby nie jechał w nieskończoność. To zabezpieczenie na wypadek błędu.
motor.run(LEFT_MOTOR, speed)
motor.run(RIGHT_MOTOR, speed)
Uruchamiamy oba silniki do przodu. Ważne: używamy motor.run (nie motor_pair) — bo za chwilę będziemy zatrzymywać każdy silnik osobno.
while not (left_done and right_done):
Pętla działa dopóki przynajmniej jeden silnik jest jeszcze aktywny. Gdy oba zatrzymane — pętla kończy się i robot stoi wyprostowany.
if not left_done and reflection(COLOR_LEFT) < 30:
motor.stop(LEFT_MOTOR); left_done = True
Jeśli lewy czujnik widzi wartość odbicia mniejszą niż 30 (czyli czarną linię) I lewy silnik jeszcze nie był zatrzymany — zatrzymujemy go i ustawiamy flagę left_done = True.
Jak dwie nogi wchodzące do pokoju: każda zatrzymuje się gdy poczuje próg. Jeśli wejdziesz krzywo, jedna noga trafi na próg wcześniej i staje — drugą dostawiasz.
motor_pair.stop(motor_pair.PAIR_1, stop=motor.BRAKE)
Na końcu pewność — zatrzymujemy oba silniki z hamowaniem. motor.BRAKE to hamowanie aktywne (jak hamulce w rowerze), a nie samo odcięcie prądu (które powoduje wybieg).
Montaż: Oba czujniki koloru muszą być symetrycznie po bokach robota, na tej samej wysokości i tej samej odległości od osi kół. Im dalej od osi tym dokładniejsze wyrównanie, ale robot musi mieć miejsce na manewr.

from color_sensor import reflection, color as cscolor
from color import Color
import time

# ── Wykrycie koloru ───────────────────────────────────
def get_color(sensor_port=None) -> str:
    """Zwraca kolor jako string: 'red','blue','green','yellow','black','white'"""
    if sensor_port is None: sensor_port = COLOR_FRONT
    COLOR_MAP = {
        Color.RED: 'red', Color.BLUE: 'blue', Color.GREEN: 'green',
        Color.YELLOW: 'yellow', Color.WHITE: 'white', Color.BLACK: 'black',
        Color.CYAN: 'cyan', Color.ORANGE: 'orange',
    }
    return COLOR_MAP.get(cscolor(sensor_port), None)

# ── Odczyt odbicia ─────────────────────────────────────
def get_reflection(sensor_port=None) -> int:
    """0 = czarny, 100 = biały. Używaj do linii i kalibracji."""
    if sensor_port is None: sensor_port = COLOR_FRONT
    return reflection(sensor_port)

# ── Czekaj na kolor ────────────────────────────────────
def wait_for_color(target_color, sensor_port=None, timeout_ms=10000):
    """Blokuje program aż czujnik wykryje zadany kolor."""
    if sensor_port is None: sensor_port = COLOR_FRONT
    start = time.ticks_ms()
    while cscolor(sensor_port) != target_color:
        if time.ticks_diff(time.ticks_ms(), start) > timeout_ms:
            return False  # timeout — nie wykryto
    return True

# ── Kalibracja ─────────────────────────────────────────
def calibrate(sensor_port=None, seconds=5):
    """Uruchom przed zawodami! Pokaż czujnik nad różnymi kolorami."""
    if sensor_port is None: sensor_port = COLOR_FRONT
    end = time.ticks_ms() + seconds * 1000
    while time.ticks_ms() < end:
        print(f"Odbicie: {reflection(sensor_port):3d}% | Kolor: {cscolor(sensor_port)}")
        time.sleep_ms(300)

Tworzymy słownik — tabelkę tłumaczeń. Czujnik zwraca wewnętrzne kody (Color.RED, Color.BLUE). My chcemy dostać zwykły tekst ('red', 'blue') żeby łatwiej pisać warunki if.

return COLOR_MAP.get(cscolor(sensor_port), None)
Odczytujemy kolor z czujnika (cscolor), szukamy go w słowniku (COLOR_MAP.get) i zwracamy polskie/angielskie słowo. Jeśli czujnik widzi kolor którego nie ma w słowniku — zwracamy None (nic).

Ta funkcja zatrzymuje cały program i czeka aż czujnik zobaczy wybrany kolor. Przydatne gdy robot ma stać i czekać na sygnał, albo powoli podjechać i wykryć znacznik misji.

🟡 Proporcjonalne — kl. 6–7
▶ Kiedy kliknięto Start

■ Zatrzymaj wszystkie silniki

  2. Blok "jasność czujnika koloru" znajdziesz w Czujniki
  3. Odejmowanie: kategoria Operatory → blok " − "
  4. Do prędkości silnika dodaj zmienną "błąd" (też Operatory → " + " i " − ")
